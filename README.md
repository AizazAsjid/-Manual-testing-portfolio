# SauceDemo Manual Testing Project

## Project Overview

This project documents a manual functional testing exercise on the SauceDemo e-commerce demo application.

**Application:** https://www.saucedemo.com/

## Testing Scope

- Login and logout functionality
- Product listing and sorting
- Shopping cart operations
- Checkout form validation
- Order completion

## Testing Approach

- Positive testing
- Negative testing
- Functional testing
- Boundary and validation checks where applicable
- Defect reporting

## Test Deliverables

- Test Plan
- Test Cases
- Test Execution Report
- Bug Reports (if defects are confirmed)
- Screenshots and testing evidence

To be updated after test execution.
